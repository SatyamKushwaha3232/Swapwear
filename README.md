# 🌸 SwapWear — Premium Clothing Swap Marketplace

SwapWear is a modern premium clothing exchange & swap marketplace built with React, Vite, and Tailwind CSS.

Designed with:
- Glassmorphism UI
- Pastel luxury aesthetic
- Dribbble-inspired layouts
- Smooth animations
- Premium hover interactions
- Responsive mobile experience

---

# ✨ Features

## 🎀 Premium UI/UX
- Liquid glass navbar
- Pastel pink accents
- Soft shadows
- Large rounded cards
- Responsive premium layout

## 🛍 Marketplace Features
- Clothing swap marketplace
- Same-product image hover slideshow
- Product video previews
- Search & filters
- Item details page
- Wishlist & listings

## 💬 Community Features
- Real-time style chat UI
- Swap requests
- Negotiation section
- Dashboard & Admin Panel

## 📱 Responsive
- Mobile dropdown navbar
- Accordion menus
- Tablet optimized layouts
- Smooth scaling
